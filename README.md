# 🍕 Pizza Sales Report Analytics | Power BI

## 📌 Project Overview

I developed an interactive **Power BI report** to analyze pizza sales data and gain meaningful insights into business performance.

## 🛠️ Tools Used

* Power BI
* MySQL
* Microsoft Excel
* DAX
* Power Query

## 📊 Key Analysis

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas per Order
* Daily & Monthly Sales Trends
* Sales by Pizza Category & Size
* Top & Bottom Selling Pizzas

## 🎯 Objective

To analyze pizza sales performance and present meaningful business insights through an interactive Power BI dashboard.

## 📷 Dashboard

The report includes interactive dashboards for:

* Pizza Sales Analysis
* Best & Worst Sellers
